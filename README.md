# Avenida Presidente Antônio Carlos

Apresentação do estudo preliminar de **qualificação urbanística e mobilidade ativa**, de **Letícia Oliveira Santos**, Arquitetura e Urbanismo / UFMG, 2026.

[Ver a apresentação](https://joaovitorsd.github.io/tcc-leticia/)

Atualizada com os materiais de 20/11/2026: monografia de 135 páginas, 10 pranchas de projeto e 5 fotomontagens. O site apresenta perspectivas atuais do projeto, comparações entre situação existente e proposta, cartografia e documentação completa.

## Abrir localmente

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory site/dist
```

Abra http://127.0.0.1:4173. Site estático sem instalação ou build.
